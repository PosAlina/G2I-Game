# G2I-Game "Mechanical Heart"

## Основные ветки

* develop - самая актуальная ветка с общими изменениями
* master - стабильная ветка, отрезается в конце каждого спринта
* realease - ветка со стабильным билдом, которая должна быть отполирована к майлстоунам Лесты

### Механики:

#### Общие механики

* WASD - перемещение
* E - взаимодействие с объектами
* Tab - переключение персонажей
* Esc - пауза

#### Механики инженера

* Space - прыжок
* ЛКМ - прицел
* ПКМ - выстрел

#### Механики дочки

* Проходит через некоторые объекты
* Полёт
* Видит невидимое

### Уровни

* Котельная
* Холл
* Детская
* Конечная локация

#### Внешние механики

* Головоломка с трубами
* Есть объекты, которые видит только первый персонаж, и есть объекты, которые видит только второй персонаж
* Вращение шестерёнок при выстреле по ним влияет на мир игры
* Порталы: персонажи проходят сквозь них
* Головоломка: активировать предметы в нужном порядке
* Музыкальная головоломка: дочь слышит звуки у каждой трубы, нужно инженером крутануть вентили у нужных труб в нужном порядке
* Слайдеры: инженер подходит, начинает взаимодействие, после этого должен установить слайдер в нужную точку, чтобы лампочки горели в нужной конфигурации
* Монометры: вращать стрелки вентилями до нужного результата
* Интерактивные виджеты: взаимодействовать с предметом можно только, если на виджете указана клавиша, которую нажимать
* Манипулятор: выстрелы по шестеренкам перемещают манипулятор так, чтобы он доставил уголь в печь
* Активация головоломок в нужном порядке, изменение мира в зависимости от решённых головоломок
* Камеры от третьего лица и фиксированная, переключающиеся
и др.
